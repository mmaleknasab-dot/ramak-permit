# سامانه پرمیت رامک — سرور شبکه داخلی + بازوی بله

## محتویات
- `server.js` — سرور وب و API (فقط Node.js، بدون نصب پکیج)
- `db.js` — دیتابیس فایل JSON مشترک
- `public/index.html` — پنل کارکنان
- `bot.js` — بازوی بله پیمانکار
- `START-SERVER.bat` / `START-BOT.bat` — اجرای آسان در ویندوز

داده همه کامپیوترها **مشترک** است و در `data/store.json` ذخیره می‌شود.

---

## ۱) نصب روی سیستم سرور کارخانه

### پیش‌نیاز
فقط [Node.js](https://nodejs.org/) (نسخه ۱۸ یا بالاتر). نیازی به `npm install` نیست.

### اجرا
1. پوشه `ramak-server` را مثلاً در `C:\ramak-server` کپی کنید.
2. دوبار کلیک روی `START-SERVER.bat`  
   یا در ترمینال:
   ```bat
   cd C:\ramak-server
   node server.js
   ```
3. آدرس شبکه را یادداشت کنید، مثلاً:
   ```text
   http://192.168.1.50:3780
   ```
4. روی کامپیوترهای کارکنان یک **شورتکات مرورگر** به همین آدرس بسازید.

### ورود
- کاربر: `admin`
- رمز: `123`  
بعد از ورود حتماً رمز را عوض کنید.

### پشتیبان‌گیری
فایل `data\store.json` را کپی کنید.

> توجه: گذاشتن فقط HTML روی Share داکیومنت داده را بین سیستم‌ها مشترک نمی‌کند.  
> باید **یک سیستم به‌عنوان سرور** `node server.js` را اجرا کند و بقیه با مرورگر به IP آن وصل شوند.

---

## ۲) بازوی بله (تست از گوشی)

### ساخت بازو
در بله از BotFather / پنل توسعه‌دهندگان توکن بگیرید.

### اجرا (ترمینال جدا — سرور باید روشن باشد)
```bat
cd C:\ramak-server
set BALE_TOKEN=توکن-اینجا
set RAMAK_API=http://127.0.0.1:3780
node bot.js
```
یا دوبار کلیک روی `START-BOT.bat` و وارد کردن توکن.

اگر سرور روی سیستم دیگری است:
```bat
set RAMAK_API=http://192.168.1.50:3780
```

### تست
1. در بله بازو را `/start` کنید.
2. شماره موبایلی بفرستید که در **ثبت قرارداد** پنل وب ثبت کرده‌اید.
3. منو: قراردادها، پرمیت‌ها، ثبت نفر، گزارش کار.

سیستم اجرای بازو باید به **اینترنت** (برای بله) و به **IP سرور** دسترسی داشته باشد.

---

## مسیر تست پیشنهادی
1. سرور را روشن کنید.
2. با admin وارد شوید و یک قرارداد با موبایل خودتان بسازید.
3. بازو را با همان موبایل وصل کنید.
4. از بله نفر ثبت کنید و در پنل وب «تأیید ورود پرسنل» را ببینید.
